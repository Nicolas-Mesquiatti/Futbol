# Instrucciones permanentes del proyecto

## Diseño y UI
- Siempre usar el skill **ui-ux-pro-max** para cualquier tarea de diseño visual o interfaz.

## Presentaciones
- Siempre aplicar el skill **presentaciones-visuales** cuando se pidan slides o presentaciones.

## Redacción
- Siempre humanizar los textos generados: lenguaje natural, cercano, sin sonar a IA.
  Evitar frases genéricas, estructuras rígidas o tono corporativo.

## Git
- Siempre hacer commit y push directo a la rama **main** únicamente.
